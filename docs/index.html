如何安裝

  1. 使用電腦版 Chrome 或 Edge 開啟本站。iPad／iPhone Safari 無法直接刷 ESP32。
  2. 以可傳輸資料的 USB-C 線接上 Paper S3，長按電源鍵直到背面紅燈閃爍，鬆開便進入下載模式。
  3. 選 Parallel 3.0 Full，點選 Install，選擇正確的序列埠並確認寫入。
  4. 兩台需安裝完全相同版本。完成後重啟，放入含 EPUB 的 SD 卡，再進 Reader 配對。
這是出廠／救援刷機：可能清除既有 Flash 設定和閱讀進度。先備份，再刷機。僅適用 M5Stack Paper S3，不適用 M4、Tab5 或其他 ESP32。
